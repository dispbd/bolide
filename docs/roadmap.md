# Roadmap

| Фаза | Срок (1 разработчик, вечера) | Цель |
|---|---|---|
| 0. Исследование и спайки | 2–3 недели | Прототип изоморфного мутатора на Hono + TanStack DB + Electric. Замерить задержки и размер бандла. Решить: своё ядро или надстройка над Hono. |
| 1. Ядро | 1–2 месяца | Роутер на Web-стандартах, `defineModule`, DI с выводом типов, жизненный цикл, конфиг, валидация через Standard Schema, OpenAPI, CLI `create`/`dev`. |
| 2. Батарейки | 1–2 месяца | Auth, кеш, очереди и крон, почта, файлы, i18n, логи и трейсинг. |
| 3. Слой данных и optimistic UI | 2–3 месяца | Общий формат схем и мутаторов, типизированный клиент, адаптеры Electric/Zero, очередь мутаций с откатом, адаптеры React и Vue. |
| 4. Собственный sync (по желанию) | 2–4 месяца | Свой CDC-транспорт для Postgres, права доступа для live-запросов, офлайн. |
| 5. Экосистема | постоянно | Документация, стартеры, адаптеры Svelte/Solid, плагин Vite, деплой-рецепты. |
